# Embedded fonts

## Requirements

The Typst module embeds no fonts itself, so the `nb` runtime must embed
fonts whose licenses permit embedding in distributed binaries.

## Font selection

Fonts will be embedded once the full Typst integration is complete.
Candidates must be under MIT, Apache-2.0, or OFL (SIL Open Font License)
which permits embedding.
